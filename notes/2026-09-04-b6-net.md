## Shape

- **`roc:sync-sockets`** is the WASI-shaped primitive layer: `TcpSocket` /
  `UdpSocket` resources; `resolve!`, `tcp_connect!/listen!/accept!`,
  `tcp_input!/output!` (mint a `roc:sync-io` stream from a cloned socket, so
  bytes flow through the *same* stream primitives files use), timeouts, ports,
  `udp_bind!/send_to!/recv!`. basic-cli's `Tcp.Stream` is `Host.TcpStream`,
  which the shim declares as an **alias** of `Sockets.TcpSocket` (not a fresh
  opaque — the shim's five tcp leaves must pass it through unchanged).
- **`roc:sync-http`** is one leaf, `HttpHost.send!`, taking basic-cli's exact
  host-request record. Response headers come back **NUL-joined** as
  `headers_flat` (R-B5: pinned glue can't build `RocList<RocStr>` host-side);
  the shim's `split_headers` rebuilds `List (Str, Str)` for verbatim `Http.roc`.
- **`[packages]` in `world.toml`** (new tool feature, `codegen.rs` emits
  `packages { http: "…" }`): verbatim `Http.roc`/`InternalHttp.roc`
  `import http.Request` etc. from the `roc-lang/http` package, so the composed
  platform must declare it. D18's composition side gained a field, nothing else.
- **`roc:testnet`** is TEST SCAFFOLDING, not a shipped interface: echo / httpd
  / delayed-connect peers on host threads so a blocking single-threaded app can
  exercise both client and listener sides. It stays out of B8's world.

## Findings

1. **basic-cli's `Method → U8` is not union order.** `to_host_method` encodes
   `CONNECT=0, DELETE=1, QUERY=2, GET=3, HEAD=4, OPTIONS=5, PATCH=6, POST=7,
   PUT=8, TRACE=9`, and `Unknown(_)` *also* maps to 2 — the host tells them
   apart by a non-empty `method_ext`. My first table (union order) passed the
   run because the test httpd ignored the verb; now the httpd answers
   `hello-http` only to a `GET`, so the encoding is under test.
2. The HTTP client is ~40 lines over `std::net` (request line, headers,
   `Connection: close`, read-to-EOF, parse status/headers). No TLS, no
   chunked decoding, no redirects — B8 decides whether the shipped
   `http-host` grows a real client crate (`ureq`-class) behind the same leaf;
   the interface doesn't change.
3. `roc check` errors met and fixed: `pf.Streams` had to be exported for the
   app's `Tcp.Stream` reads; `Tcp.Stream.write_utf8!`/`read_up_to!` live on the
   `Stream` module, not `Tcp`; `Http.get_utf8!` takes a `Url`, not `Str`.
4. Owned-argument rule held: every `RocStr`/list arg is decref'd after copying,
   sockets are touched only through `resource::with`; `live()==0` at exit.
