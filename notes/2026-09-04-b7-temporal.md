## Shape

- **Records vs resources.** `PlainDate {year: I32, month: U8, day: U8}`,
  `PlainTime`, `Duration` (ten `I64` fields) cross as plain records — no
  refcount, no destructor, structural equality for free. `ZonedDateTime`,
  `TimeZone`, `Calendar` are `Box(U64)` resources wrapping the `temporal_rs`
  values directly. A `PlainDate` record is ISO fields; calendar-aware ops
  take an explicit `Calendar` resource (`date_add!(date, dur, calendar)`), so
  the record stays plain data and the calendar is the only stateful part.
- **Overflow** is Temporal's default `constrain` (Jan 31 + 1 month = Feb 29);
  `until` uses `DifferenceSettings::default()` (largest unit = day).
- **Errors** `[Range(Str), TypeErr(Str), Syntax(Str), Other(Str)]` mirror
  Temporal's RangeError/TypeError/SyntaxError.
- `temporal_rs = "=0.2.6"` default features (`sys-local` → bundled tzdb, no
  system tzdata dependency). Only `temporal-host` depends on it.

## Findings

1. **Glue emits a Rust keyword as a field name.** A tag `Type(Str)` became
   `pub type: ManuallyDrop<RocStr>` in the payload union — `generated.rs`
   fails to parse. Renamed to `TypeErr`. Interface authors must avoid tag
   names that lowercase to Rust keywords (`type`, `match`, `ref`, `box`, …)
   until the glue escapes them with `r#`.
2. **Glue dedups identical result types**: `zdt_with_time_zone!` returns the
   same `Try(ZonedDateTime, Err)` as `zdt_from_epoch_ns!`, and there is no
   `TemporalZdtWithTimeZoneResult` — the host reuses
   `TemporalZdtFromEpochNsResult`. Names are by first declaration, so
   reordering leaves in `interface.toml`/the module can rename host types.
3. **`temporal_rs` 0.2.6 keeps `ErrorKind` private** — no public `kind()`;
   the host classifies on the error's Debug form. Ugly but contained in one
   function; revisit when the crate exposes it.
4. **No `Num.to_str` in the pinned compiler** — it's `U8.to_str`,
   `I32.to_str`, `I64.to_str` etc. (`Num` has no `to_str`).
5. Re-composing is required after editing an interface's `.roc`: `build.sh`
   glues `platform/main.roc`, which `compose` regenerates — a stale platform
   silently glues the old surface.
6. **`set -o pipefail` + `grep -q` is a false negative** on a long producer:
   `grep -q` exits at the first match, `nm`/`ar` die of SIGPIPE, the pipeline
   fails, and `||` reports "no symbols" for an archive with 825 of them. Every
   gate's `verify.sh` runs under `pipefail`; probe with `grep … >/dev/null`
   (reads to EOF) instead of `-q` whenever the producer is big.

## Exit ✅

`verify.sh`: compose/build/run, exact ten-line stdout, exit 0, `nm` shows
