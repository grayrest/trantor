## Hosted surface — `TerminalDevice` (phase 1)

```roc
TerminalDevice :: [].{
	Tty :: Box(U64)                                   # [[resources]]; owned → close on drop, shared → nothing (D-K1-7, D-K1-21)
	Stream : [Stdin, Stdout, Stderr]
	Mode : [Cooked, Cbreak, Raw]                      # D-K1-8
	Input : [Bytes(List(U8)), Resized, Resumed, TimedOut]   # D-K1-6

	is_terminal! : Stream => Bool                     # isatty on fd 0/1/2, never /dev/tty
	open! : {} => Try(Tty, [NoTerminal, TerminalErr(IOErr)])       # also registers SIGWINCH (D-K1-25), received on its own thread (D-K1-29)
	shared! : {} => Try(Tty, [NoTerminal, TerminalErr(IOErr)])     # the process-wide fd, borrowed (D-K1-21)
	mode! : Tty => Try(Mode, [TerminalErr(IOErr)])    # what is in force now; with_mode! restores to it
	set_mode! : Tty, Mode => Try({}, [TerminalErr(IOErr)])
	size! : Tty => Try({ cols : U16, rows : U16 }, [UnknownSize, TerminalErr(IOErr)])   # D-K1-15
	read! : Tty, U64 => Try(Input, [TerminalErr(IOErr)])
	write! : Tty, List(U8) => Try({}, [TerminalErr(IOErr)])
	set_restore! : Tty, { enter : List(U8), exit : List(U8) } => Try({}, [RestoreTooLarge, TerminalErr(IOErr)])
	suspend! : Tty => Try({}, [TerminalErr(IOErr)])   # raise SIGTSTP; returns after SIGCONT (D-K1-24)
}
```

`mode!` is not in the log's sketch; it is the read side `with_mode!` needs to
"restore what it found" (D-K1-8) and adds no decision. `RestoreTooLarge` is the
named form of D-K1-9's cap error. `mode!` reports the mode the *guard* last set
(or `Cooked` before any), not a classification of arbitrary termios.

Error rows follow trantor-cli's closed unions; the shim/batteries widen.

### Host internals (`components/terminal-host/src/`)

| File | Owns |
|---|---|
| `lib.rs` | the ten leaves; `Tty` resource: `enum TtyFd { Owned(OwnedFd), Shared(RawFd) }`, drop closes only `Owned` |
| `device.rs` | `open("/dev/tty", O_RDWR \| O_CLOEXEC \| O_NOCTTY)`; `ENXIO` (measured, no ctty) / `ENOENT` → `NoTerminal`. The process-wide fd: opened once on first `shared!` or `install()`, never closed |
| `mode.rs` | `Mode` → termios from the *saved original*: `Cbreak` clears ICANON\|ECHO; `Raw` is `cfmakeraw`; `Cooked` is the original. `TCSANOW` always (D-K1-26) |
| `guard.rs` | process-global state: saved original termios (once), current mode, active flag, exit-written flag, restore buffer; `install()` once on first `set_mode!` or `set_restore!`: `libc::atexit(teardown_at_exit)`, disposition-checked signal registration (D-K1-19); `teardown()`. At `open!`: SIGWINCH registered, blocked on the calling thread, and received by one parked thread that blocks every other signal (D-K1-29) |
| `restore.rs` | the enter/exit buffer: `AtomicPtr<Buf>`, fixed cap 4096; register = allocate, swap, leak old (D-K1-9) |
| `wake.rs` | self-pipe (non-blocking both ends, `O_CLOEXEC`); handler writes one tag byte: `W` resize, `C` continue |
| `read.rs` | wait over tty fd + wake fd: **`select` on `target_vendor = "apple"`, `poll` elsewhere** (D-K1-20); retry `EINTR` with the remaining budget from a monotonic clock (D-K1-25); wake bytes drained → `Resized`/`Resumed` (resize before resume if both); else `read` available bytes |

The guard writes teardown bytes to the process-wide fd, so a dropped owned
`Tty` cannot close the fd a signal handler writes to, and `shared!` hands out
that same fd as `Shared` so no Roc drop can close it either (D-K1-21).

**Measure before choosing the `select` shape (D-K1-20):** on Darwin, whether
`rustix::event::select` (or `libc::select` with a heap-allocated set) accepts
an fd ≥ `FD_SETSIZE` (1024). If it does, no limit; if not, `open!` returns
`TerminalErr` for such an fd rather than corrupting memory. Record the result
in the design log.

### Signal handling (D-K1-2, D-K1-3, D-K1-11)

Registered through `signal_hook_registry::register_unchecked`.

**Disposition check (D-K1-19).** At `install()`, for each *fatal* signal below,
read the current disposition with `libc::sigaction(sig, null, &mut old)`. If it
is `SIG_IGN` or a handler, **do not register**: someone has claimed that signal,
the process will not die of it, and when it exits `atexit` restores. Register
only signals still at `SIG_DFL`. A handler installed by someone else *after*
`install()` replaces ours outright; that process also exits through `atexit`.

Fatal set (default action terminates or stops, D-K1-19): SIGTERM,
SIGHUP, SIGQUIT, SIGINT, SIGPIPE, SIGALRM, SIGUSR1, SIGUSR2, SIGXCPU, SIGXFSZ,
SIGVTALRM, SIGPROF; and SIGTSTP (stop). SIGCONT and SIGWINCH are always
registered — their actions never terminate, so chaining them is harmless.
SIGSEGV/SIGBUS/SIGILL/SIGFPE are forbidden by the registry and are not handled:
a Roc stack overflow (SIGSEGV; the driver's C `main` installs no Rust overflow
handler) leaves the terminal for `reset`. The README says so.

Ours, async-signal-safe only:

| Signal | Guard active | Guard inactive |
|---|---|---|
| fatal set except SIGTSTP | teardown; `emulate_default_handler` | `emulate_default_handler` |
| SIGTSTP | teardown; `emulate_default_handler` (stops, reported as SIGSTOP — cosmetic) | `emulate_default_handler` |
| SIGCONT | `tcsetattr(current mode)`; write enter bytes; clear exit-written; wake `C` | nothing |
| SIGWINCH (on the receiver thread, D-K1-29) | wake `W` | wake `W` |

Registered-but-inactive emulates the default, which is exactly what the process
would have done without the package, since we only registered where the
disposition was `SIG_DFL`.

"Active" = mode ≠ Cooked or restore buffer non-empty. SIGINT is included
because Cbreak keeps ISIG on (D-K1-8, D-K1-18).

**Teardown (D-K1-23):** write exit bytes *if* the exit-written flag is clear, then
set it; then `tcsetattr(original)` **unconditionally** (idempotent, so a nested
signal can never skip the restore). `atexit` teardown blocks the fatal set with
`pthread_sigmask` first, so no signal interrupts it; it takes no default action.
SIGCONT clears the exit-written flag after re-entering, so a later exit writes
the exit bytes again.

**`suspend!` (D-K1-24):** `signal_hook::low_level::raise(SIGTSTP)`. With SIGTSTP
registered, the handler tears down and stops; SIGCONT re-enters and wakes `C`,
so the next `read!` returns `Resumed`. If SIGTSTP was claimed or ignored,
`suspend!` delivers it to the claimant and returns — documented.

## Phase 1 — device and guard

**P1.1 skeleton.** `package.toml`, `interfaces/terminal`, empty `terminal-host`
compiling, `tty-shim`. `trantor test .` steps 1–3 pass (driver refused alone,
composes with dev-deps, negative control).

**P1.2 host leaves** per the tables above.

**P1.3 `tty-shim`.** `Tty.enable_raw_mode! : () => {}`, `disable_raw_mode! : () => {}`
over a lazily opened process-wide `Tty` and `set_mode!(Raw | Cooked)`; failures
are swallowed because upstream's signature is infallible — the doc says so.
`is_terminal! : [Stdout, Stderr] => Bool` matching the rocjust fork
(`seahaven/platform/Tty.roc`). Nothing else.

The lazy handle: the shim cannot hold Roc state across calls, so it calls
`shared!` each time, which returns the process-wide fd as a `Shared` `Tty`
whose drop does nothing (D-K1-18, D-K1-21). Do not add a global anywhere else.

**P1.4 `tests/no-cc/test.sh`.** Compose, then `cargo tree -e build,normal -i cc`
in the composed workspace must not match. Positive control: copy the package to
`$TMP`, enable `signal-hook`'s `extended-siginfo-raw`, compose, require a match.

**P1.5 `tests/pty/`.** `test.sh` composes `$DEPS` + the package, builds each
`apps/<scenario>/main.roc`, then `cargo test --release --manifest-path
harness/Cargo.toml` with `SCENARIO_BIN_DIR` set. The harness opens a pty
(`rustix::pty::openpt`/`grantpt`/`unlockpt`/`ptsname`), spawns the app with the
slave as its controlling terminal (`setsid` + `TIOCSCTTY` via `rustix`), keeps
its own slave fd open, and **drains the master on a thread from spawn** into a
shared buffer (D-K1-23: measured on macOS, a pty child hangs in exit until its
output is read). Assertions read that buffer and `tcgetattr` on the slave.
Keys are sent only after the app prints its readiness marker, never on a timer.

## Phase 2 — input

**P2.1 `terminal-keys`: `Keys`.** Types exactly as D-K1-12 (with `Reply` from
D-K1-14). `Decoder` opaque; `feed`, `flush`. Parser states: ground, ESC, CSI
(params, intermediates), SS3, OSC (terminated by BEL or ST), bracketed paste
(until `ESC[201~`, spanning feeds). Mouse: SGR only. UTF-8 assembled across
feeds; invalid → `Unknown`. Expects per D-K1-16 (~40).

**P2.2 `terminal-lib`: `Terminal`.**

```roc
Terminal :: {
	tty : TerminalDevice.Tty,
	decoder : Keys.Decoder,
	pending : List(Event),                              # D-K1-22: resize/resume during a wait are kept
	restore : List({ enter : List(U8), exit : List(U8) }),
	sync : [Unknown, Supported, Unsupported],
}
Event : [Input(Keys.Input), Resized, Resumed, TimedOut]
ColorDepth : [None, Ansi16, Ansi256, TrueColor]
Query : [CursorPos, KittyFlags, Background, Mode(U16)]

open! : {} => Try(Terminal, [NoTerminal, TerminalErr(IOErr), ..])
next_event! : Terminal, U64 => Try((Terminal, Event), [TerminalErr(IOErr), ..])
with_mode! : Terminal, Mode, (Terminal => Try((Terminal, a), [ModeFailed(IOErr), ..e]))
             => Try((Terminal, a), [ModeFailed(IOErr), ..e])        # D-K1-22: measured form
push_restore! : Terminal, { enter : List(U8), exit : List(U8) } => Try(Terminal, [RestoreTooLarge, TerminalErr(IOErr), ..])
pop_restore! : Terminal => Try(Terminal, [TerminalErr(IOErr), ..])
sync_supported : Terminal -> [Unknown, Supported, Unsupported]
with_sync_supported : Terminal, [Supported, Unsupported] -> Terminal
query! : Terminal, Query, U64 => Try((Terminal, [Answered(Keys.Reply), Unsupported]), [TimedOut, TerminalErr(IOErr), ..])
size! : Terminal => Try({ cols : U16, rows : U16 }, [UnknownSize, TerminalErr(IOErr), ..])
write! : Terminal, List(U8) => Try({}, [TerminalErr(IOErr), ..])
color_depth! : {} => ColorDepth
```

`Event` wraps `Keys.Input` (D-K1-18). Record fields of a nominal are not
readable from another module (measured, D-K1-22), so `Ansi` and `Screen` reach
`restore` and `sync` only through the four accessors. `push_restore!` writes
`enter`, pushes, and re-registers the concatenated stack with `set_restore!`;
`pop_restore!` writes the top `exit`, pops, re-registers. Nothing else in the
record is exposed.

`next_event!`: drain `pending`; else `read!` with the caller's timeout; on
`Bytes`, `feed`; if the decoder holds a partial sequence, `read!(25)` and
`flush` on `TimedOut`. Escape timeout is a named constant. A `Resized` or `Resumed` returned during that
wait goes to `pending`, never dropped.

`query!`: write request + `CSI c`; loop `read!` within the budget; matching
`Reply` → `Answered`; `DeviceAttributes` first → `Unsupported`; anything else
→ `pending` (including `Resized`/`Resumed`).

`color_depth!`: `NO_COLOR` set and non-empty → `None`; `COLORTERM` ∈
{`truecolor`,`24bit`} → `TrueColor`; `TERM` contains `256color` → `Ansi256`;
`TERM` = `dumb` or unset → `None`; else `Ansi16`. Via trantor-cli `Env`.

**P2.3 pty rows:** query answered (harness replies), unsupported (harness
replies DA1 only), timed out (harness silent), key typed between request and
reply is the next `next_event!`; escape timeout (`ESC` alone → `Esc` after
~25 ms; `ESC [ A` in one write → `Up`); `with_mode!` nesting (Cbreak inside Raw
returns to Raw; body `Err` still restores).

**P3.1 `terminal-ansi`: `Ansi`.** Pure builders returning `List(U8)`: cursor

**P3.3 `tests/graphemes/`.** The generator also emits `GraphemeBreakTest.txt`

**P3.4 `terminal-screen`: `Screen`.**

Screen :: { cols : U16, rows : U16, cells : List(Cell), prev : List(Cell), depth : ColorDepth }
Cell : { grapheme : Str, style : Ansi.Style }   # a wide grapheme's second column holds ""

## Implementation record

### Phase 1 — done (trantor-terminal `64dd5f0`, `3653a87`, `05c086e`; trantor `dbbd19a`)

`trantor test .` passes: 26 pty rows, four mutation controls each failing their
rows, and the no-`cc` gate with its control. b8 is 26/26 with `tty` and
`terminal-app-snake` checked by name and run over a pty.

Departures from the text above, each within its decision:

- **`mode! : Tty => Mode`**, not `Try`: it reads the guard's record and cannot fail.
- **`register_sigaction`**, not `register_unchecked`: every signal in the set is
  one the checked form accepts, so the unchecked form bought nothing.
- **Teardown and SIGCONT skip the terminal when the process is not in its
  foreground group.** `tcsetattr` from the background is answered with SIGTTOU,
  which stops the process: exiting after `bg`, or `bg` itself, would have
  stopped it. The terminal was already restored at the stop.
- **D-K1-20 measured:** rustix 1.1.4's Apple `select` is
  `_DARWIN_UNLIMITED_SELECT`-shaped; a descriptor above 1024 waits correctly
  (`a_descriptor_above_fd_setsize_still_waits`). No limit, no named error.
- **rustix's Apple `select` rounds nanoseconds up into `tv_usec` without
  carrying**, so a remaining budget such as 59.9999995 s became
  `tv_usec = 1_000_000` and Darwin returned EINVAL on the first real read. The
  host rounds to whole microseconds before building the `Timespec`.
- **The harness reads termios through the master.** On macOS the session
  leader's exit revokes the slave; `tcgetattr` on the harness's slave
  descriptor is ENOTTY exactly when the exit rows need it. A row proves master
  and slave agree while the child lives.
- **PENDIN is masked** when comparing settings: the kernel sets it on a correct
  restore when canonical mode returns with input queued.
- **Rows run 4 at a time**: 26 parallel rows exhausted macOS's ptys (`openpt`
  ENXIO).
- The scenario world names `exports = ["Probe"]`; a world's own module is
  private otherwise, and the list adds to the packages' exports.
- b8's pty run uses a `pty-script` binary added to the harness rather than a
  second pty implementation in trantor.

### Phase 2 — done (trantor-terminal `b8d0682`, `b65de87`)

`trantor test .`: 73 of the package's own expects (61 for the decoder), 33 pty
rows, seven mutation controls.

- **Keys is four modules plus a test module**, to stay under 300 lines:
  `KeyTypes` (the types; `Keys` re-aliases them), `KeyText` (bytes and UTF-8),
  `KeyEscapes` (ESC, SS3, OSC framing), `KeyCsi` (what a CSI means), and

- **`Terminal.suspend!`** forwards `TerminalDevice.suspend!`: a Raw program
