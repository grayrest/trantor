## Hosted surface — `TerminalDevice` (phase 1)

```roc
TerminalDevice :: [].{
	Tty :: Box(U64)                                   # [[resources]]; destructor closes the fd (D-K1-7)
	Stream : [Stdin, Stdout, Stderr]
	Mode : [Cooked, Cbreak, Raw]                      # D-K1-8
	Input : [Bytes(List(U8)), Resized, Resumed, TimedOut]   # D-K1-6

	is_terminal! : Stream => Bool                     # isatty on fd 0/1/2, never /dev/tty
	open! : {} => Try(Tty, [NoTerminal, TerminalErr(IOErr)])
	mode! : Tty => Try(Mode, [TerminalErr(IOErr)])    # what is in force now; with_mode! restores to it
	set_mode! : Tty, Mode => Try({}, [TerminalErr(IOErr)])
	size! : Tty => Try({ cols : U16, rows : U16 }, [UnknownSize, TerminalErr(IOErr)])   # D-K1-15
	read! : Tty, U64 => Try(Input, [TerminalErr(IOErr)])
	write! : Tty, List(U8) => Try({}, [TerminalErr(IOErr)])
	set_restore! : Tty, { enter : List(U8), exit : List(U8) } => Try({}, [RestoreTooLarge, TerminalErr(IOErr)])
}
```

`mode!` is not in the log's sketch; it is the read side `with_mode!` needs to
"restore what it found" (D-K1-8) and adds no decision. `RestoreTooLarge` is the
named form of D-K1-9's cap error. `mode!` reports the mode the *guard* last set
(or `Cooked` before any), not a classification of arbitrary termios.

Error rows follow trantor-cli's closed unions; the shim/batteries widen.

### Host internals (`components/terminal-host/src/`)

| File | Owns |
|---|---|
| `lib.rs` | the eight leaves; `Tty` resource (fd, dropped → `close`) |
| `device.rs` | `open("/dev/tty", O_RDWR \| O_CLOEXEC \| O_NOCTTY)`; `ENXIO` / `ENOENT` / no ctty → `NoTerminal` |
| `mode.rs` | `Mode` → termios from the *saved original*: `Cbreak` clears ICANON\|ECHO; `Raw` is `cfmakeraw`; `Cooked` is the original. `TCSAFLUSH` for Raw/Cbreak entry, `TCSANOW` for restore |
| `guard.rs` | process-global state: saved original termios (once), current mode, active flag, restore buffer; `install()` once on first `set_mode!` or `set_restore!`: `libc::atexit(teardown_at_exit)`, signal registration; `teardown()` |
| `restore.rs` | the enter/exit buffer: `AtomicPtr<Buf>`, fixed cap 4096; register = allocate, swap, leak old (D-K1-9) |
| `wake.rs` | self-pipe (non-blocking both ends, `O_CLOEXEC`); handler writes one tag byte: `W` resize, `C` continue |
| `read.rs` | `poll` over tty fd + wake fd with the timeout; wake bytes drained → `Resized`/`Resumed` (resize before resume if both); else `read` available bytes |

The guard's own fd for teardown is a separate `/dev/tty` open made at
`install()` and never closed, so a dropped `Tty` cannot close the fd a signal
handler writes to.

### Signal handling (D-K1-2, D-K1-3, D-K1-11)

Registered through `signal_hook_registry::register_unchecked` (handler order is
previous handler → ours). Ours, async-signal-safe only:

| Signal | Action when guard active | When inactive |
|---|---|---|
| SIGTERM, SIGHUP, SIGQUIT | write exit bytes; `tcsetattr(original)`; `emulate_default_handler` | `emulate_default_handler` |
| SIGINT | same as above (reaches us only in Cooked/Cbreak, where ISIG is on) | `emulate_default_handler` |
| SIGTSTP | write exit bytes; `tcsetattr(original)`; `emulate_default_handler` (stops) | `emulate_default_handler` |
| SIGCONT | `tcsetattr(current mode)`; write enter bytes; wake `C` | nothing |
| SIGWINCH | wake `W` | wake `W` |

"Active" = mode ≠ Cooked or restore buffer non-empty. SIGINT is not in D-K1-2's
list but Cbreak keeps ISIG on (D-K1-8), so Ctrl-C in Cbreak must take the same
path; this is the stated meaning of "Ctrl-C still kills, the guard restores".
Emulating the default when inactive keeps a handler-installed process
indistinguishable from one without the package (D-K1-11).

`atexit` teardown is the same as the SIGTERM row without the default action.
Idempotent: a teardown flag (atomic) prevents a double write when a signal
arrives during `exit()`.

### Dependencies (pin exact)

```toml
rustix = { version = "=1.1.4", features = ["termios", "event", "fs", "stdio"] }
signal-hook-registry = "=1.4.8"
signal-hook = { version = "=0.4.4", default-features = false }
libc = "=0.2.189"
```

`signal-hook` only if `emulate_default_handler` is used from it; if
`signal-hook-registry` alone suffices plus a hand-written emulation, raise it
rather than hand-write. Confirm the feature names against the crates before
pinning.

## Phase 1 — device and guard

**P1.1 skeleton.** `package.toml`, `interfaces/terminal`, empty `terminal-host`
compiling, `tty-shim`. `trantor test .` steps 1–3 pass (driver refused alone,
composes with dev-deps, negative control).

**P1.2 host leaves** per the tables above.

**P1.3 `tty-shim`.** `Tty.enable_raw_mode! : () => {}`, `disable_raw_mode! : () => {}`
over a lazily opened process-wide `Tty` and `set_mode!(Raw | Cooked)`; failures
are swallowed because upstream's signature is infallible — the doc says so.
`is_terminal! : [Stdout, Stderr] => Bool` matching the rocjust fork
(`seahaven/platform/Tty.roc`). Nothing else.

The lazy handle: the shim cannot hold Roc state across calls, so the host keeps
the process-wide `Tty` for it — a ninth leaf `shared! : {} => Try(Tty, …)`
returning the same fd each call. Raise at implementation if a cleaner shape
appears; do not add a global anywhere else.

**P1.4 `tests/no-cc/test.sh`.** Compose, then `cargo tree -e build,normal -i cc`
in the composed workspace must not match. Positive control: copy the package to
`$TMP`, enable `signal-hook`'s `extended-siginfo-raw`, compose, require a match.

**P1.5 `tests/pty/`.** `test.sh` composes `$DEPS` + the package, builds each
`apps/<scenario>/main.roc`, then `cargo test --release --manifest-path
harness/Cargo.toml` with `SCENARIO_BIN_DIR` set. The harness opens a pty
(`rustix::pty::openpt`/`grantpt`/`unlockpt`/`ptsname`), spawns the app with the
slave as its controlling terminal (`setsid` + `TIOCSCTTY` via `rustix`), keeps
its own slave fd open until the master is drained, and asserts from the master
side with `tcgetattr` on the slave.

One test per row; apps are minimal and named for the row:

| Scenario | App does | Harness asserts |
|---|---|---|
| mode-cbreak / mode-raw | set mode, print `ready`, block on read | slave termios flags per D-K1-8; after `q`, original restored |
| exit-ok, exit-err | Raw + restore pair, then `Ok` / `Err` | exit status; original termios; exit bytes present, after enter bytes |
| exit-crash | Raw, then `crash` | status 1; restored |
| exit-panic | Raw, then a host leaf that panics (test-only component in `apps/`) | status 70; restored |
| exit-cli | Raw, then `Cli.exit!(3)` | status 3; restored |
| sig-term, sig-hup, sig-quit | Raw, block | harness signals; killed-by-signal status; restored; exit bytes |
| sig-int-cbreak | Cbreak, block | harness writes `^C`; killed by SIGINT; restored |
| sig-tstp-cont | Raw, loop printing mode on `Resumed` | SIGTSTP → stopped and cooked; SIGCONT → raw again, enter bytes rewritten, app prints `resumed` |
| chain | installs a recording handler before first `set_mode!` (test-only component), Raw, block | SIGTERM → recording handler's marker written AND restored |
| inactive | opens, never changes mode, block | SIGTERM → killed-by-signal, no bytes written |
| resize | print size, wait for `Resized`, print size | `TIOCSWINSZ` on master → second size matches |
| read-zero | `read!(0)` with nothing pending | returns `TimedOut` in < 50 ms |
| no-terminal | `open!` | spawned without ctty (`setsid`, no slave) → prints `NoTerminal` |
| shim | the upstream `tty.roc` verbatim (URL swapped) | raw during read, restored after |
| restore-cap | `set_restore!` with 4097 bytes | `RestoreTooLarge` |

Positive controls (in `test.sh`, each a copy of the package in `$TMP` with one
line patched, rows re-run and required to FAIL):
- `atexit` registration removed → exit-ok/err/crash/panic/cli fail.
- registration via plain `sigaction` replacing (not chaining) → chain fails.
- teardown not writing exit bytes → the exit-bytes assertions fail.

**P1.6 b8.** In trantor: b8's world adds `trantor-terminal` to `[deps]`; remove
the `tty`/`terminal-app-snake` exclusion; floor 18 → 20; add a snake run over a
pty (reuse the harness binary via a small `--script` mode, or a Python-free
equivalent — raise if neither fits) sending `d d q`, asserting exit 0 and the
terminal restored. Update the b8 comment that says where Tty went.

Phase 1 done: `trantor test .` green in trantor-terminal; `just verify` green in
trantor.

## Phase 2 — input

**P2.1 `terminal-keys`: `Keys`.** Types exactly as D-K1-12 (with `Reply` from
D-K1-14). `Decoder` opaque; `feed`, `flush`. Parser states: ground, ESC, CSI
(params, intermediates), SS3, OSC (terminated by BEL or ST), bracketed paste
(until `ESC[201~`, spanning feeds). Mouse: SGR only. UTF-8 assembled across
feeds; invalid → `Unknown`. Expects per D-K1-16 (~40).

**P2.2 `terminal-lib`: `Terminal`.**

```roc
Terminal :: { tty : TerminalDevice.Tty, decoder : Keys.Decoder, pending : List(Keys.Input) }
Event : [Input(Keys.Input), Resized, Resumed, TimedOut]
ColorDepth : [None, Ansi16, Ansi256, TrueColor]
Query : [CursorPos, KittyFlags, Background, Mode(U16)]

open! : {} => Try(Terminal, [NoTerminal, TerminalErr(IOErr), ..])
next_event! : Terminal, U64 => Try((Terminal, Event), [TerminalErr(IOErr), ..])
with_mode! : Terminal, Mode, (Terminal => Try((Terminal, a), e)) => Try((Terminal, a), [ModeFailed(IOErr)]e)
query! : Terminal, Query, U64 => Try((Terminal, [Answered(Keys.Reply), Unsupported]), [TimedOut, TerminalErr(IOErr), ..])
size! : Terminal => Try({ cols : U16, rows : U16 }, [UnknownSize, TerminalErr(IOErr), ..])
write! : Terminal, List(U8) => Try({}, [TerminalErr(IOErr), ..])
color_depth! : {} => ColorDepth
```

`Event` wraps `Keys.Input` rather than flattening Key/Mouse/… into it; the log
names `Event` without fixing its shape, and wrapping keeps a replacement
`Keys` from forcing a `Terminal` change. Raise if a flat union is wanted.

`next_event!`: drain `pending`; else `read!` with the caller's timeout; on
`Bytes`, `feed`; if the decoder holds a partial sequence, `read!(25)` and
`flush` on `TimedOut`. Escape timeout is a named constant.

`query!`: write request + `CSI c`; loop `read!` within the budget; matching
`Reply` → `Answered`; `DeviceAttributes` first → `Unsupported`; anything else
→ `pending`. For `Query.DeviceAttributes` itself the sentinel is the answer.

`color_depth!`: `NO_COLOR` set and non-empty → `None`; `COLORTERM` ∈
{`truecolor`,`24bit`} → `TrueColor`; `TERM` contains `256color` → `Ansi256`;
`TERM` = `dumb` or unset → `None`; else `Ansi16`. Via trantor-cli `Env`.

**P2.3 pty rows:** query answered (harness replies), unsupported (harness
replies DA1 only), timed out (harness silent), key typed between request and
reply is the next `next_event!`; escape timeout (`ESC` alone → `Esc` after
~25 ms; `ESC [ A` in one write → `Up`); `with_mode!` nesting (Cbreak inside Raw
returns to Raw; body `Err` still restores).

## Phase 3 — output

**P3.1 `terminal-ansi`: `Ansi`.** Pure builders returning `List(U8)`: cursor
move/save/restore/show/hide, erase, SGR (`Style : { fg, bg, bold, dim, italic,
underline, reverse, strike }`, `Color : [Default, Ansi16(U8), Ansi256(U8),
Rgb(U8, U8, U8)]`) with `ColorDepth` downsampling, scroll region, alt screen,
mouse (`?1000`+`?1002`+`?1006`), paste (`?2004`), focus (`?1004`), kitty push/pop,
sync (`?2026`). Scoped helpers over `Terminal` and `set_restore!`:
`with_alt_screen!`, `with_cursor_hidden!`, `with_mouse!`, `with_bracketed_paste!`,
`with_focus_events!`, `with_kitty_keyboard!` (queries first, D-K1-14). The
restore stack lives in `Terminal` — add a `restore : List({ enter, exit })` field;
this is the stack D-K1-9 describes and adds no decision.

Downsampling: Rgb → 256 by nearest in the 6×6×6 cube and 24-step grey ramp;
256 → 16 by the xterm default palette nearest. Tests at boundary values.

**P3.2 `terminal-width`: `Width`.** `gen/` is a Rust bin (no Python) reading a
pinned Unicode version's `EastAsianWidth.txt`, `emoji-data.txt`,
`GraphemeBreakProperty.txt`, `DerivedCoreProperties.txt` (checked into
`gen/ucd/<version>/`) and emitting range tables as Roc. Version: the latest
released at implementation time; recorded in the README and the table header.
`tests/width-tables/test.sh` regenerates and diffs. `Width.graphemes : Str -> List(Str)`
(UAX #29 extended), `Width.of : Str -> U16` (W/F → 2; zero-width and
combining → 0; emoji presentation or VS16 → 2; else 1; a grapheme's width is
its first scalar's unless VS16).

**P3.3 `tests/graphemes/`.** The generator also emits `GraphemeBreakTest.txt`
as Roc data; `main.roc` runs every vector and prints `pass=N fail=0`;
`expected` pins N; `test.sh`-free. The expectation file itself proves >1000.

**P3.4 `terminal-screen`: `Screen`.**

```roc
Screen :: { cols : U16, rows : U16, cells : List(Cell), prev : List(Cell), depth : ColorDepth }
Cell : { grapheme : Str, style : Ansi.Style }   # a wide grapheme's second column holds ""
new : { cols : U16, rows : U16 }, ColorDepth -> Screen
put : Screen, { col : U16, row : U16 }, Str, Ansi.Style -> Screen   # clips; uses Width
resize : Screen, { cols : U16, rows : U16 } -> Screen               # forces full redraw
render : Screen -> (Screen, List(U8))                               # pure diff; the tested unit
flush! : Terminal, Screen => Try((Terminal, Screen), [TerminalErr(IOErr), ..])
```

`flush!` = `render` + one `write!`, wrapped in `?2026` begin/end when the
terminal answered `Mode(2026)` supported (queried once, cached in `Terminal` —
another field; raise if that grows further).

**P3.5 README.** Layers, both replacement routes (D-K1-10), the exit-path
table and what `reset` is for, `_exit` in a chained handler, Unix only,
Unicode version. Its ```roc blocks are built by `trantor test .` step 5.
